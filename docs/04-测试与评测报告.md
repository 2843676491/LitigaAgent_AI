## 结论（按实测自动生成）

1. **红线守住了**：引用有效率 1.00、无证据定性率 0.00——这是「敢给法务看」的前提，任何版本回退都必须拦。
2. **法条召回是主要瓶颈**（0.60 < 0.85）：BM25 词面匹配 + 小规模语料的必然结果，下一步应换 BGE-M3 语义向量并扩法条库到全量，而不是继续调 top_k。
3. **HITL 触发率落在目标区间**（0.25）：复核闸门既不过载也不空转。
4. **风险/倾向一致率偏低**（0.62 / 0.50）：评分是启发式加权，且标注本身有主观性；需与法务共同校准权重后再作为对外指标。
5. **Mock 的定位**：它不追求论证质量，价值在于把收敛、冲突、引用校验、HITL、审计这些工程机制压成可回归的基线。
